EMERGENCY INFORMATION MANAGER - UPDATED PROJECT
================================================

TECHNOLOGIES
------------
1. HTML: creates the webpage structure and emergency helpline cards.
2. CSS: styles the page, pink helpline cards and responsive layout.
3. JavaScript: adds, edits and deletes personal contacts, saves notes,
   manages document references, uses localStorage and exports JSON.

FILES
-----
index.html
- Contains the website structure.
- Includes six emergency helpline cards.
- Includes a 112 national emergency call notice.
- Includes forms for personal contacts, notes and document references.
- HTML comments explain the tags and attributes.

style.css
- Controls colours, spacing, card layout, typography and responsiveness.
- CSS comments explain the selectors and properties.

script.js
- Controls all interactive features.
- Comments explain variables, DOM selection, functions, events,
  localStorage, arrays, objects and export.

HOW TO RUN
----------
1. Extract this ZIP file.
2. Open the extracted Emergency_Information_Manager_Updated folder in VS Code.
3. Open index.html.
4. Right-click index.html and choose "Open with Live Server".
   If Live Server is not installed, open index.html in a web browser.

HOW TO USE
----------
1. Emergency Helplines: tap a number on a compatible phone to open its
   calling application.
2. My Emergency Contacts: add, edit or delete your own contact details.
3. Quick Access: use the Call link for a saved personal contact.
4. Allergies & Important Notes: type notes and select Save Notes.
5. Important Documents: save a document name and optional web link.
6. Export Information: download the saved information as a JSON file.

IMPORTANT HELPLINE NOTES
------------------------
The cards are a student-project reference, not a guarantee that every
number is active in every location.

112 is India's unified national emergency number.

102 is listed by the National Portal of India as the National Ambulance
Service.

1075 is listed as the Central COVID-19 helpline; it should not be labelled
as a general health-information helpline.

1066 is listed as an anti-poison number in a CBSE reference for New Delhi.
Confirm local availability before relying on it.

108, 1091 and 1098 may have service/coverage details that should be checked
with current official local sources.

PRIVACY LIMITATION
------------------
This is a frontend learning project. localStorage is not encrypted and
the project has no login or server-side security. Use sample information
only; do not enter sensitive real medical or identity information.
